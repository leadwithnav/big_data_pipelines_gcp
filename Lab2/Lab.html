Step 1: Set Environment Variables

Export PROJECT_ID in Cloud Shell.

💡 Google Cloud Pub/Sub
Google Cloud Pub/Sub is an asynchronous, serverless messaging service that decouples event-producing publishers from event-processing subscribers.

Activate Cloud Shell and set your active GCP Project ID.

Linux / macOS (BASH) 
# Auto-detect your active GCP Project ID
export PROJECT_ID=$(gcloud config get-value project)
echo "Project ID : $PROJECT_ID"
PowerShell (BASH) 
# Set active GCP Project ID in PowerShell
$env:PROJECT_ID=(gcloud config get-value project)
Write-Host "Project ID : $env:PROJECT_ID"
  • Set PROJECT_ID Variable Confirm PROJECT_ID environment variable is set using gcloud config get-value project.

Step 2: Create Pub/Sub Topic (`lab2-topic`) & Subscription (`lab2-sub`)

Provision the Pub/Sub topic and pull subscription using gcloud CLI.

📢 Topics & Subscriptions
Publishers send messages to a Topic (`lab2-topic`). Subscriptions (`lab2-sub`) pull or stream messages published to that topic.

Run `gcloud pubsub` commands to create topic `lab2-topic` and subscription `lab2-sub`.

Linux / macOS (BASH) 
# Create the Pub/Sub Topic
gcloud pubsub topics create lab2-topic --project=${PROJECT_ID}

# Create a pull subscription bound to the topic
gcloud pubsub subscriptions create lab2-sub --topic=lab2-topic --project=${PROJECT_ID}
PowerShell (BASH) 
# Create the Pub/Sub Topic
gcloud pubsub topics create lab2-topic --project=$env:PROJECT_ID

# Create a pull subscription bound to the topic
gcloud pubsub subscriptions create lab2-sub --topic=lab2-topic --project=$env:PROJECT_ID
  • Create Topic Run gcloud pubsub topics create lab2-topic.
  • Create Subscription Run gcloud pubsub subscriptions create lab2-sub --topic=lab2-topic.

Step 4: Run the Telemetry Publisher (`publisher.py`)

Publish IoT sensor records from `sensor_data.csv` continuously to `lab2-topic`.

📤 Telemetry Streaming Publisher
`publisher.py` reads `sensor_data.csv`, injects current UTC timestamps, and continuously streams JSON payload records to `lab2-topic`.

Execute `publisher.py` in your primary Cloud Shell terminal tab and keep it running.

Linux / macOS (BASH) 
# Run Telemetry Publisher (keep terminal tab open)
python publisher.py --project=${PROJECT_ID}
PowerShell (BASH) 
# Run Telemetry Publisher (keep terminal tab open)
python publisher.py --project=$env:PROJECT_ID
  • Launch Publisher Run python publisher.py --project=${PROJECT_ID}.
  • Verify Output Logs Confirm Published message ID logs are displayed in terminal.

Step 5: Run the Telemetry Subscriber (`subscriber.py`)

Open a second terminal tab and run `subscriber.py` to consume and acknowledge messages in real-time.

📥 Message Pull & Acknowledgment
`subscriber.py` listens to `lab2-sub`, processes incoming telemetry payloads in real-time, and sends message acknowledgments (`ack`) back to Pub/Sub.

Open a **new Cloud Shell terminal tab**, navigate to Lab2, set `PROJECT_ID`, and run `subscriber.py`.

Linux / macOS (BASH) 
# In a NEW Cloud Shell terminal tab:
cd ~/big_data_pipelines_gcp/Lab2
export PROJECT_ID=$(gcloud config get-value project)

# Run Telemetry Subscriber
python subscriber.py --project=${PROJECT_ID}
PowerShell (BASH) 
# In a NEW PowerShell terminal tab:
cd D:\trainings\GCP_Big_Data_Pipelines\Lab2
$env:PROJECT_ID=(gcloud config get-value project)

# Run Telemetry Subscriber
python subscriber.py --project=$env:PROJECT_ID
  • Open Second Terminal Tab Launch a second terminal session.
  • Launch Subscriber Run python subscriber.py --project=${PROJECT_ID}.
  • Verify Received Payload Confirm Received message ID logs and message acknowledgments in terminal.

Step 6: End-to-End Verification & Cleanup

Stop publisher and subscriber scripts and delete Pub/Sub topic and subscription.

🧹 Resource Cleanup
Stop active streaming background scripts with Ctrl+C and delete topic/subscription resources to avoid unexpected GCP charges.

Press `Ctrl+C` in both terminal tabs to stop scripts, then delete `lab2-sub` and `lab2-topic`.

Linux / macOS (BASH) 
# 1. Press Ctrl+C in Tab 1 (publisher.py) and Tab 2 (subscriber.py) to stop

# 2. Delete Pub/Sub resources in terminal:
gcloud pubsub subscriptions delete lab2-sub --project=${PROJECT_ID}
gcloud pubsub topics delete lab2-topic --project=${PROJECT_ID}
PowerShell (BASH) 
# 1. Press Ctrl+C in Tab 1 (publisher.py) and Tab 2 (subscriber.py) to stop

# 2. Delete Pub/Sub resources in terminal:
gcloud pubsub subscriptions delete lab2-sub --project=$env:PROJECT_ID
gcloud pubsub topics delete lab2-topic --project=$env:PROJECT_ID
  • Stop Scripts Press Ctrl+C in both terminal windows.
  • Delete Pub/Sub Resources Delete subscription lab2-sub and topic lab2-topic.
