Step 3: Load `movies.csv` into HDFS

Open JupyterLab Terminal and copy `movies.csv` into HDFS distributed storage.

📁 HDFS Storage
Hadoop Distributed File System (HDFS) distributes file blocks across cluster node disks for parallel high-throughput reading by Spark executors.

In JupyterLab Launcher, click **Terminal** to open a bash terminal on the master node, then run `hdfs dfs` commands to stage `movies.csv` in `/data/`.

Linux / macOS (BASH) 
# In JupyterLab Terminal on Master VM:
hdfs dfs -mkdir -p /data

# Put local movies.csv into HDFS /data directory
hdfs dfs -put movies.csv /data/

# Verify dataset exists in HDFS
hdfs dfs -ls /data
PowerShell (BASH) 
# In JupyterLab Terminal on Master VM:
hdfs dfs -mkdir -p /data

# Put local movies.csv into HDFS /data directory
hdfs dfs -put movies.csv /data/

Step 4: Open & Run PySpark Jupyter Notebook (`lab_01_intro.ipynb`)

Execute interactive PySpark DataFrame transformations and aggregations.

⚡ PySpark Transformations & Aggregations
Spark transformations (`filter`, `withColumn`, `explode`, `groupBy`) build execution plans. Actions (`show`, `write`) execute distributed physical computation.

In JupyterLab file browser, double-click `lab_01_intro.ipynb`, select **PySpark** kernel, and run notebook cells sequentially.

Linux / macOS (PYTHON) 
from pyspark.sql import SparkSession
from pyspark.sql.functions import col, desc, explode, split, avg

# 1. Initialize SparkSession
spark = SparkSession.builder \
    .appName("Lab 1 - Intro to PySpark - Movies") \
    .getOrCreate()

# 2. Read dataset from HDFS
file_path = "/data/movies.csv"
df_movies = spark.read.csv(file_path, header=True, inferSchema=True)
df_movies.printSchema()
df_movies.show(5, truncate=False)

# 3. Filter modern movies (released >= 2000)
df_modern_movies = df_movies.filter(col("year") >= 2000)
df_modern_movies.show(5, truncate=False)

# 4. Explode pipe-delimited genres and compute average rating per genre
df_exploded_genres = df_movies.withColumn("genre", explode(split(col("genres"), "\\|")))
df_genre_ratings = df_exploded_genres.groupBy("genre") \
    .agg(avg("rating").alias("avg_rating")) \
    .orderBy(desc("avg_rating"))
df_genre_ratings.show(10, truncate=False)

# 5. Write aggregated result back to HDFS/Storage
df_genre_ratings.repartition(1).write.mode("overwrite").csv("output/genre_ratings", header=True)
