Step 1: System Architecture & Terraform Provisioning

Provision GCP infrastructure using Infrastructure as Code (IaC) with Terraform.

🏢 Enterprise Retail Architecture
This capstone implements an end-to-end streaming and batch data lakehouse architecture handling Orders, Inventory, and Customer events using Pub/Sub, Dataflow, PySpark, Iceberg, and BigQuery.

Apply Terraform configuration (`main.tf`) to provision Pub/Sub topics (`orders-events`, `inventory-events`, `customer-events`), GCS buckets (`iceberg-raw`, `iceberg-curated`), and BigQuery dataset `retail_analytics`.

Linux / macOS (BASH) 
cd capstone_project/terraform
terraform init
terraform apply -var="project_id=[YOUR_PROJECT_ID]" -auto-approve
PowerShell (BASH) 
cd capstone_project/terraform
terraform init
terraform apply -var="project_id=[YOUR_PROJECT_ID]" -auto-approve
  • Run Terraform Init Initialize HashiCorp GCP Provider plugins.
  • Apply Infrastructure Config Provision Pub/Sub topics, GCS buckets, and BigQuery dataset.

Step 2: Streaming Telemetry Ingestion (`mock_events_publisher.py`)

Publish simulated retail transactions into Pub/Sub topics.

🛒 Real-Time Streaming Events
Simulate high-velocity retail sales, stock level changes, and customer transactions across multiple store IDs.

Execute `mock_events_publisher.py` to stream continuous JSON telemetry events into Pub/Sub.

Linux / macOS (PYTHON) 
python capstone_project/publisher/mock_events_publisher.py \
  --project_id=[YOUR_PROJECT_ID] \
  --num_events=500
PowerShell (PYTHON) 
python capstone_project/publisher/mock_events_publisher.py `
  --project_id=[YOUR_PROJECT_ID] `
  --num_events=500
  • Inspect JSON Schemas Review order_event.json and inventory_event.json schemas.
  • Run Mock Publisher Stream 500 synthetic retail events to Pub/Sub.

Step 3: Dataflow Streaming Pipeline to Iceberg Raw Storage

Deploy Apache Beam streaming pipeline (`streaming_pipeline.py`) to Dataflow.

🌊 Dataflow Ingestion Layer
Dataflow validates JSON schemas, converts records into Beam NamedTuples, and streams data into GCS Raw Iceberg storage.

Deploy `streaming_pipeline.py` on Cloud Dataflow.

Linux / macOS (PYTHON) 
python capstone_project/dataflow/streaming_pipeline.py \
  --runner=DataflowRunner \
  --project=[YOUR_PROJECT_ID] \
  --region=us-central1 \
  --temp_location=gs://[YOUR_PROJECT_ID]-iceberg-raw/temp \
  --staging_location=gs://[YOUR_PROJECT_ID]-code-bin/staging
PowerShell (PYTHON) 
python capstone_project/dataflow/streaming_pipeline.py `
  --runner=DataflowRunner `
  --project=[YOUR_PROJECT_ID] `
  --region=us-central1 `
  --temp_location=gs://[YOUR_PROJECT_ID]-iceberg-raw/temp `
  --staging_location=gs://[YOUR_PROJECT_ID]-code-bin/staging
  • Submit Dataflow Streaming Job Deploy streaming pipeline to DataflowRunner.
  • Verify GCS Raw Iceberg Tables Confirm Iceberg metadata files arrive in gs://[PROJECT_ID]-iceberg-raw.

Step 4: Batch ETL & Curation with PySpark on Dataproc

Run `spark_etl_job.py` on Dataproc to aggregate Raw into Curated Iceberg storage.

⚡ Spark Batch Curation
PySpark batch jobs read Raw Iceberg storage, perform deduplication, aggregate daily sales revenue by store, and write to Curated Iceberg storage.

Submit PySpark batch curation job on Dataproc.

Linux / macOS (BASH) 
gcloud dataproc jobs submit pyspark capstone_project/dataproc/spark_etl_job.py \
  --cluster=ephemeral-dataproc-cluster \
  --region=us-central1 \
  -- --project_id=[YOUR_PROJECT_ID]
PowerShell (BASH) 
gcloud dataproc jobs submit pyspark capstone_project/dataproc/spark_etl_job.py `
  --cluster=ephemeral-dataproc-cluster `
  --region=us-central1 `
  -- --project_id=[YOUR_PROJECT_ID]
  • Run PySpark Batch Curation Execute spark_etl_job.py on Dataproc.
  • Verify Curated Tables Confirm curated_sales_daily table is generated in GCS Curated bucket.

Step 5: End-to-End Orchestration & BigQuery Analytics

Orchestrate workflow with Airflow (`orchestration_dag.py`) and query in BigQuery.

📊 Retail Analytics Workspace
Execute analytical SQL queries in BigQuery over external and managed Iceberg tables to track daily revenue and store stock levels.

Deploy Airflow DAG to Cloud Composer and run business intelligence SQL queries in BigQuery.

Linux / macOS (SQL) 
-- Daily Revenue Aggregation Query in BigQuery
SELECT store_id, SUM(total_sales_amount) as daily_revenue
FROM retail_analytics.sales_daily_external
GROUP BY store_id
ORDER BY daily_revenue DESC;
PowerShell (SQL) 
-- Daily Revenue Aggregation Query in BigQuery
SELECT store_id, SUM(total_sales_amount) as daily_revenue
FROM retail_analytics.sales_daily_external
GROUP BY store_id
ORDER BY daily_revenue DESC;
  • Deploy Airflow Orchestration DAG Copy orchestration_dag.py to Composer DAGs bucket.
  • Run BigQuery Lakehouse Queries Execute analytical SQL queries over Iceberg tables in BQ Studio.
