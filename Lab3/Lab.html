Step 1: Environment & API Setup

Enable Dataflow and Compute Engine APIs and set up GCS staging bucket.

💡 Google Cloud Dataflow
Dataflow is a fully managed, serverless unified stream and batch processing service powered by Apache Beam.

Enable APIs and provision a staging GCS bucket for Apache Beam pipeline artifacts.

Linux / macOS (BASH) 
gcloud services enable dataflow.googleapis.com compute.googleapis.com pubsub.googleapis.com
gsutil mb -l us-central1 gs://[YOUR_PROJECT_ID]-dataflow-staging
PowerShell (BASH) 
gcloud services enable dataflow.googleapis.com compute.googleapis.com pubsub.googleapis.com
gsutil mb -l us-central1 gs://[YOUR_PROJECT_ID]-dataflow-staging
  • Enable GCP APIs Confirm Dataflow and Pub/Sub APIs are enabled.
  • Create Staging GCS Bucket Create Cloud Storage bucket for Dataflow temp binaries.

Step 2: Pub/Sub Infrastructure Setup

Create Pub/Sub topic and subscription for streaming ingestion.

📡 Streaming Source
Dataflow pipelines connect to Pub/Sub topics as real-time unbounded streaming sources.

Create topic `dataflow-sensor-topic` and subscription `dataflow-sensor-sub`.

Linux / macOS (BASH) 
gcloud pubsub topics create dataflow-sensor-topic
gcloud pubsub subscriptions create dataflow-sensor-sub --topic=dataflow-sensor-topic
PowerShell (BASH) 
gcloud pubsub topics create dataflow-sensor-topic
gcloud pubsub subscriptions create dataflow-sensor-sub --topic=dataflow-sensor-topic
  • Create Topic Provision dataflow-sensor-topic.
  • Create Subscription Provision dataflow-sensor-sub.

Step 3: Developing Apache Beam Code (`lab_03_dataflow.py`)

Write Apache Beam pipeline code with custom DoFn transforms.

🧱 Apache Beam PTransforms & DoFn
Beam pipelines transform `PCollection` data using parallel `ParDo` operations with custom `DoFn` classes.

Review Beam pipeline code filtering high-temperature sensor readings from Pub/Sub stream.

Linux / macOS (PYTHON) 
# lab_03_dataflow.py snippet
import apache_beam as beam
from apache_beam.options.pipeline_options import PipelineOptions
import json

class FilterHighTempFn(beam.DoFn):
    def process(self, element):
        record = json.loads(element.decode('utf-8'))
        if float(record.get('temperature', 0)) > 80.0:
            yield record

def run():
    options = PipelineOptions(streaming=True, save_main_session=True)
    with beam.Pipeline(options=options) as p:
        (p | 'ReadFromPubSub' >> beam.io.ReadFromPubSub(subscription='projects/[PROJECT]/subscriptions/dataflow-sensor-sub')
           | 'FilterHighTemp' >> beam.ParDo(FilterHighTempFn())
           | 'LogOutput' >> beam.Map(print))
PowerShell (PYTHON)

Step 4: Local Execution (DirectRunner) vs Cloud (DataflowRunner)

Test locally with DirectRunner, then submit job to Cloud Dataflow.

🚀 DataflowRunner Deployment
DataflowRunner automatically provisions worker VMs, auto-scales resources, and handles fault tolerance.

Deploy the streaming pipeline to GCP Dataflow using `DataflowRunner`.

Linux / macOS (BASH) 
# Test locally
python lab_03_dataflow.py --runner=DirectRunner

# Deploy to Cloud Dataflow
python lab_03_dataflow.py \
  --runner=DataflowRunner \
  --project=[YOUR_PROJECT_ID] \
  --region=us-central1 \
  --temp_location=gs://[YOUR_PROJECT_ID]-dataflow-staging/temp \
  --job_name=lab03-streaming-sensor
PowerShell (BASH) 
# Test locally
python lab_03_dataflow.py --runner=DirectRunner

# Deploy to Cloud Dataflow
python lab_03_dataflow.py `
  --runner=DataflowRunner `
  --project=[YOUR_PROJECT_ID] `
  --region=us-central1 `
  --temp_location=gs://[YOUR_PROJECT_ID]-dataflow-staging/temp `
  --job_name=lab03-streaming-sensor
  • Test DirectRunner Run local DirectRunner execution.
  • Submit Dataflow Job Deploy streaming job with DataflowRunner.

Step 5: Monitoring Job & Teardown

Inspect job graph and watermarks in Dataflow UI, then drain/cancel the job.

⏹️ Job Cancellation
Streaming Dataflow jobs run indefinitely until explicitly cancelled or drained.

Open GCP Dataflow Console, view execution graph, and cancel the active streaming job.

Linux / macOS (BASH) 
gcloud dataflow jobs list --region=us-central1
gcloud dataflow jobs cancel [JOB_ID] --region=us-central1
PowerShell (BASH) 
gcloud dataflow jobs list --region=us-central1
gcloud dataflow jobs cancel [JOB_ID] --region=us-central1
  • Monitor Dataflow Graph Inspect System Lag and Data Watermarks in Dataflow UI.
  • Cancel Dataflow Job Run gcloud dataflow jobs cancel command.
